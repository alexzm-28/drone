## 解释与边界

这些结果仅证明实现与该组仿真条件中的行为。默认机载水平速度PI为8s⁻¹、4s⁻²，机载降落使用理想水平位置传感器；改变内环带宽或传感器假设可能改变结果。图像没有镜头畸变、模糊或复杂地面背景。不能据此声称实物也能达到毫米或厘米级精度。

落地后必须满足四个脚点与电极重叠的条件才能充电。充电采用有效功率能量模型，时钟加速60倍；飞行动力学和飞行耗电不加速。

早期模型曾出现强风下对接失败、精对准超时；相关条件已保存为 `tests/regression_cases.json` 中的4个回归用例。当前验收没有删去或缩小这些随机化条件。

GitHub Actions 另行运行 Linux 环境下的自动测试和较小规模的图像/故障实验。运行状态应以仓库 Actions 页面为准，不用本地结果替代云端结果。
