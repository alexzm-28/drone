# 仿真设计与验收

## 范围

项目以室内小型四旋翼为对象，研究地面朝上摄像头辅助的自主对准、着陆、充电与复飞。不实现实物通信或实物控制，不声称复现 Tello 内部固件。场景与控制均在本地运行。

## 坐标系与接口

- 世界坐标：X 向右，Y 向前，Z 向上，单位米。偏航绕 +Z 逆时针为正，单位弧度。
- 机体坐标：+X 为右，+Y 为前，+Z 为上。
- 外环输入为时间戳位姿 `Pose` 和模拟机载/平台传感器 `Telemetry`。
- 外环输出为机体系速度 `Command(right, forward, up, yaw_ccw)`，单位 m/s、rad/s，以及单次动作 `land`、`release`、`takeoff`。
- 外环模块不导入 MuJoCo，不持有仿真器引用。世界真实坐标只用于机载闭环、虚拟传感器、显示和实验评估。

水平世界速度到机体速度的转换：

```text
v_right   = cos(yaw) * vx + sin(yaw) * vy
v_forward = -sin(yaw) * vx + cos(yaw) * vy
```

## 动力学与时序

MuJoCo 解算自由刚体的平动、转动、重力、碰撞与摩擦。机体质量 0.087kg，主惯量为 (0.00014, 0.00014, 0.00024)kg·m²；它们是可调的工程假设。

- 物理步长 5ms；外环控制步长 40ms。
- 所有任务时限、PID、指令延迟、传感器延迟都使用同一仿真时钟，不使用墙上时间。
- 播放快慢和录制耗时不会改变积分步长；同一配置与种子可重复运行。
- 相机和指令各有独立的 FIFO 延迟队列，默认均为 80ms。

外环每轴使用 PID，含积分限幅、饱和时停止积分和低通微分。相同的相机帧不会重复积分。内部速度控制器产生期望加速度，叠加重力后得到推力方向；姿态环产生力矩，驱动刚体转动。推力只能沿机体 Z 轴施加，横向运动必须通过倾斜实现。

```text
a_desired = K_velocity * (v_command - v_measured) + Ki_velocity * integral
F_desired = mass * (a_desired + [0,0,9.81])
F_actual  = thrust * body_Z + wind_force - linear_drag
thrust    = first_order_lag(target_thrust, tau=55ms)
```

推力限幅为质量×16m/s²，水平期望倾角上限约18.3度。姿态控制使用旋转矩阵的叉积误差。没有逐个电机、电池电压下陷、桨叶流场、桨叶碰撞或电机故障模型。

内环水平速度PI增益为8s⁻¹、4s⁻²，竖直为5s⁻¹、2s⁻²；内环增益同样是配置项。它们表达一个反应较快的机载速度环假设，不是实测值。外环增益、传感器延迟、风扰和机载环带宽共同决定可达到的着陆精度。

风扰使用确定性的水平正弦加速度；默认幅值 0.045m/s²。地面效应为离地高度指数衰减的附加升力，最大约6%；地面高度按是否位于平台上方选择。它用于观察低空响应变化，不能代替空气动力学实验。

## 图像与可观测性

地面相机位于平台中心上方 4.5cm，朝 +Z，640×480，垂直视场70度。OpenCV 光学坐标轴与本场景世界轴一致。内参由渲染器分辨率与视场角计算，不使用真实摄像头的占位标定值。

机底为边长10cm、ID 7 的 ArUco 4×4 标签，带一格白色边界。使用唯一编码避免普通棋盘格180度朝向歧义。场景程序生成标签几何，不需要外部材质。

OpenCV 检测四角并做亚像素细化，用 `solvePnP` 估计姿态；拒绝负深度或重投影误差超过2像素的结果。标签到机体中心的偏移通过姿态矩阵补偿。机载降落在高度34cm时接管，避免低空标签超出相机视场导致流程停滞。

图像模式的丢帧为识别结果丢弃，强制遮挡为实际空白图像。图像模式没有加“真实位置加噪声”的补偿，也不会在检测失败后读真实坐标继续飞。当前渲染未加入镜头畸变、滚动快门、运动模糊、曝光变化或真实地面杂波，需在报告中保留这些边界。

`pose` 模式提供快速的几何视场限制与合成噪声，仅作为控制实验。两类结果分组统计。

## 状态机

| 状态 | 进入下一阶段的条件 |
|---|---|
| ACQUIRE | 得到未过期的有效图像位姿 |
| ALIGN | 水平误差<2.5cm、偏航误差<6度，连续保持0.8s |
| DESCEND | 以0.12m/s下降；误差>5.5cm或偏航>12度回到ALIGN；高度≤34cm时悬停精对准，误差<1.8cm、偏航<4度、视觉估计的滤波水平速度<0.05m/s保持0.4s后发land |
| LAND | 模拟机载降落控制；平台/地面接触保持后停电机，且速度<0.04m/s才确认落地 |
| DOCK | 电机已停、平台接触、位置与偏航合格、四脚位于各自电极范围，保持1s |
| CHARGE | 对接接触仍有效，且充电后SOC达到64% |
| RELEASE | 模拟释放反馈到达，才能发起飞动作 |
| REFLY | 机载起飞控制达到0.86m高度以上（目标0.9m） |
| COMPLETE | 本轮任务结束并悬停显示结果 |
| ABORT | 中止任务、单次发送land，继续物理仿真直至真实落地或故障降落观察期限 |

首次视觉丢失即输出零速度，正在下降时退回对准；连续丢失超过2秒中止。位姿超过250ms即视为过期。飞行SOC低于15%也中止降落。降落、对接、充电、释放、复飞均有各自超时；正常机载降落超时12秒，故障降落最长观察30秒。

获取和对准流程总计超过60秒时也中止。机载降落会锁定接管时的水平位置，并用理想机载水平位置传感器保持位置。这是独立于地面相机的内环能力假设，未加入机载光流失效或高度传感器误差；因此低空降落结果可能比真实环境乐观。

落地不能仅由高度阈值或一段倒计时确认。`land` 期间即使没有视觉，接触检测与停机流程仍会独立运行。故障降落可能落在平台外的地面；这可算故障安全落地，但不算任务成功。

## 对接与能量

平台半径24cm，台面高4cm。四个模拟脚接点位于机体 (±6.5cm, ±6.5cm)，四个圆形电极半径3.5cm。接触传感器同时要求：已落地、电机关闭、碰到平台、中心误差≤4.5cm、偏航<12度、倾角<6度、四脚水平投影均位于对应电极内，并稳定1秒。

储能按4.18Wh估计；飞行功率15W，待机0.1W，充电有效功率2.5W。默认仅充电时间加速60倍：

```text
SOC_delta = power_W * dt_seconds / (3600 * capacity_Wh)
```

充电时以上增量乘以 `charge_time_scale`。飞行耗电不乘以该系数。默认只从60%附近充到64%后复飞，演示的是补能流程，而非完整充满。

电极导电、接触电阻、CC/CV曲线、温度、磁吸力和机构运动没有建模；释放用0.5秒后到达的虚拟反馈表示。它们属于明确的工程抽象。

## 验收证据

1. 图像定位：多个位置和偏航下，从实际渲染图像恢复的位置误差<3.5cm、偏航误差<0.06rad；遮挡、出视场不输出位姿。
2. 控制保护：过期、未来或非有限位姿无效；丢视觉停止下降；机体系方向正确；PID积分不在饱和时持续增加；仿真时钟单调。
3. 动力学：关推力后受重力下落，电机响应不瞬时跳变；同种子运行可重复。
4. 完整任务：图像模式必须实际经历LAND、DOCK、CHARGE、RELEASE、REFLY，不能跳过接触或能量条件。
5. 统计：分别记录合成传感器与图像模式的成功率、误差、耗时和触地速度；保存每次配置和种子。
6. 故障：短遮挡应可恢复；持续遮挡、过期传感器、出视场、低电量应中止并落地关闭电机。故障用例不能被记为正常任务成功。

测试和报告只证明所实现模型与所列场景中的行为。没有真机测量数据，不能声明对实物的控制性能。
